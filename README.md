# Sales Prediction using Machine Learning

Sales prediction using Linear Regression and Python

## Objective

The objective of this project is to predict sales using machine learning based on factors such as Quantity, Price, and Discount.

## Dataset

The dataset contains 100 sales records with information such as Product, Region, Quantity, Price, Discount, and Sales.

For the machine learning model:
- **Features:** Quantity, Price, Discount
- **Target:** Sales


## Tools & Libraries

- **Python** — Programming language used for the project.
- **Pandas** — Used for data loading, cleaning, organizing, and analysis.
- **Matplotlib** — Used for data visualization.
- **Seaborn** — Used for statistical and attractive visualizations.
- **Scikit-learn** — Used for building, training, prediction, and evaluation of the machine learning model.
